Indido Apparel - Font Configuration Reference
=============================================

This file saves the typography configuration options you explored for the website. 
You can copy and paste these definitions back into your `src/styles/global.css` file at any time.

--------------------------------------------------------------------------------
SAVED SELECTION: Option 6 — "Editorial Vanguard"
--------------------------------------------------------------------------------
Vibe: High-contrast, runway-ready fashion editorial look. Clean, sharp, and very premium.

1. Google Fonts @import (Place at the very top of global.css):
@import url("https://fonts.googleapis.com/css2?family=Bodoni+Moda:ital,opsz,wght@0,6..96,400..900;1,6..96,400..900&family=Mulish:wght@300;400;500;600;700&display=swap");

2. CSS Variables (Place inside :root {...}):
--font-heading: 'Bodoni Moda', 'Playfair Display', 'DM Serif Display', serif;
--font-body: 'Mulish', 'Outfit', 'Manrope', sans-serif;
